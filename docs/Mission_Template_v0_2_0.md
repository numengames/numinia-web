## 📌 Mini-Guide — How to fill a mission

1. Start with the **Story Statement** — if you can't write it, the mission isn't clear yet.
2. Fill **Epistemic Value** only if there's genuine uncertainty to resolve; leave blank if purely executional.
3. **Acceptance Criteria** are non-negotiable — no criteria, no mission.
4. Tag the **Agent type** honestly: if an AI can do 80% but needs human review, it's 🔀 Hybrid.
5. Fill **Learning outcome** in Epistemic Value after completion — this is how the Guild grows.
